# Extension

存放对 GF_X、Unity 和常用组件的通用扩展方法。

直接脚本：`ConfigExtension.cs`、`DOTweenExtension.cs`、`DataTableExtension.cs`、`EntityExtension.cs`、`GF.cs`、`LocalizationExtension.cs`、`ResourceExtension.cs`、`SettingExtension.cs`、`SoundExtension.cs`、`StaticUIComponent.cs`、`TransformExtension.cs`、`UIExtension.cs`、`UnityUIExtension.cs`、`UtilityEx.cs`。

子目录：`Animation`、`AwaitExtension`、`DataModel`、`Variable`、`VariablePool`。

修改本目录代码后，应执行 Unity 编译和对应测试。
