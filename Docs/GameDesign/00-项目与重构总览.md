# ColorTiming 项目与重构总览

> 状态：功能基线已盘点，迁移实施中。

## 一句话说明

ColorTiming 是一款俯视角动作 Boss 战项目：玩家从菜单进入两场连续战斗，拾取带颜色与类型的武器，依据 Boss 当前弱点颜色攻击，并在移动、冲刺、受击、提示、暂停、音频和镜头反馈构成的实时战斗中完成 Boss1 与 Boss2。

## 当前唯一需求

当前项目没有新增玩法、关卡、数值或美术需求。唯一需求是把源工程的功能合同迁移到基于 GF_X 的目标工程，并修复已批准的源缺陷。未在源项目中观察到的功能不属于当前验收范围。

## 核心体验与不可变合同

- 操作直接：键鼠移动、瞄准、攻击、冲刺、丢弃和暂停均需可用。
- 战斗可读：玩家能从 HUD、颜色、教程、音效、命中、镜头和 Boss 行为判断当前目标。
- 颜色弱点是主循环：正确颜色只消耗一段 Boss 进度，错色不能偷伤害。
- 过程连续：StartMenu → Boss1 → Boss2 → 结果或重开／返回菜单，场景切换没有重复 UI、音频或残留实体。
- 修复优先：`FIX-001` 至 `FIX-004` 是已经批准的正确行为，而非需要复现的源缺陷。
