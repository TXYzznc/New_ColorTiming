# 系统关系与场景流程

## 场景职责

| 场景 | 玩家可见职责 | 运行时边界 |
|---|---|---|
| `Launch` | 初始化后进入产品流程 | GF 启动、配置、服务组合；当前不展示框架默认 Loading 进度条。 |
| `StartMenu` | 播放视频、菜单、设置、选择关卡 | 页面由 GF.UI 管理；BGM 由 GF.Sound 管理；不常驻旧 `LoadScenes` 或 BGM `AudioSource`。 |
| `Boss1` | 第一场十一段弱点战斗 | 场景只承载关卡与战斗对象；`BattlePresentationInstaller (Clone)` 在绑定后动态打开 HUD／教程并接收结果。 |
| `Boss2` | 第二场十五段头尾协同战斗与最终结果 | 同上；负责尾部激活、潜地和结束结果，动态表现桥随场景卸载。 |

## 运行关系

```text
Launch / StartupProcedure
  → CompositionRoot 注册项目服务
  → SceneFlow 请求目标场景
  → GF.UI 打开项目 Loading Form（输入封锁、进度、淡出）
  → GF.Scene 完成切换
  → 对应 UIForm / 实体按需打开或显示

MainMenu UIForm ─→ GF.Sound（菜单 BGM、UI 音效）
InputModule ─→ 玩家控制与 UI 输入
GF.Entity / UI pool ─→ 动态对象；名称统一为 *(Clone)
```

## 生命周期不变量

1. 每次产品场景切换仅有一个项目 Loading UI；Loading 进度单调前进，并使用非缩放时间淡出。
2. UI 页面是 GF.UI Form Prefab；正式页面层级不在运行时临时拼装，只有可复用列表 Item 可以实例化。
3. BGM、UI、玩家、Boss、环境声音按 SoundGroup 归属，离开场景或关闭页面时停止对应生命周期内的声音。
4. 所有运行时创建或从池复用的对象，都以精确后缀 `(Clone)` 标识；不得重复追加后缀。
5. 场景中仅保存必要的关卡静态内容与明确的锚点；跨场景服务、Loading、菜单 BGM 和瞬时表现不得通过旧 `DontDestroyOnLoad` 场景对象隐式常驻。
6. `Boss1`／`Boss2` 不保存 Canvas、EventSystem、`UI_Game`、`UI_WeaponTip` 或 `BattleHudContext`；`BattleTutorial` 与 `BattleHud` 均由 GF.UI 动态管理。
7. Launch 的 `WorldUIRoot` 是空的 Transform 挂载点；未来 World Space UI 的 Prefab 自己携带 Canvas，当前 Screen Space UI 不得挂入该根。
