# 产品边界与重构原则

## 已确认边界

- 保持源项目三场景与两场 Boss 的可观察玩法合同。
- 保持源资源身份、动画事件、Spine 事件、UnityEvent 所驱动的产品路径，除非已登记为批准修复。
- 使用 Unity 2022.3.62f3、URP、GF_X、UGUI 与 TextMeshPro；输入必须经过项目输入抽象。
- 框架核心位于 `Assets/Game/ScriptsBuiltin/`；ColorTiming 业务扩展位于 `Assets/Game/Scripts/ColorTiming/` 或相应业务目录。

## 不在当前范围

- 新 Boss、新武器、新关卡、新成长／存档系统或未来叙事。
- 将当前基线改造成通用示例或向框架基线回写 ColorTiming 内容。
- 因“更优雅”而静默改变源项目可见的数值、节奏、颜色规则或资源表现。

## 重构原则

| 原则 | 要求 |
|---|---|
| 行为优先 | 先用验收清单锁住体验，再替换实现。 |
| 分层所有权 | 场景负责静态关卡；GF 服务负责跨场景；GF.UI/GF.Sound/GF.Entity 负责各自生命周期。 |
| 配置驱动 | 表、资源路径、Group 和 Prefab 标识集中配置；ScriptableObject 仅作配置载体。 |
| 动态可辨识 | 运行时创建／复用对象统一 `(Clone)` 后缀，便于层级和日志诊断。 |
| 证据闭环 | 代码编译、EditMode、PlayMode、人工录像和资源审计按风险组合，不以单一日志代替全部验证。 |
