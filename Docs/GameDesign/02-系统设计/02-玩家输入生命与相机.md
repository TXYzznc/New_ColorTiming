# 玩家、输入、生命与相机

| 功能 ID | 功能合同 | 重构实现约束 | 验收要点 |
|---|---|---|---|
| CT-PLAYER-01 | WASD／方向键移动，鼠标决定朝向；待机／移动动画和翻转同步。 | 输入经 InputModule；角色逻辑与 Animator 事件保持明确边界。 | 四向移动、左右攻击生成点与动画。 |
| CT-PLAYER-02 | 普通攻击可用，命中生成 `HitFX_Nor` 且播放音效。 | 命中对象必须实现 `I_Damage`；瞬时 FX 走可回收实体／池。 | 命中有效和无效目标、回收。 |
| CT-PLAYER-03 | Dash 有事件驱动无敌窗口；穿过可伤害判定恢复 1 HP 并触发约 0.45 倍慢动作。 | Dash、受击、暂停、死亡的时间状态必须可恢复且不互锁。 | 窗口内外伤害、回血、暂停中断。 |
| CT-PLAYER-04 | 5 HP；受击一次扣一格、击退／闪烁／短无敌／强制丢武器；0 HP 死亡并允许重开。 | Hero HUD 订阅明确的生命状态，不直接依赖场景查找。 | 连击防重复、死亡输入封锁、重开。 |
| CT-WORLD-01 | 相机正交尺寸、Confiner2D、Impulse、死亡相机和视差正确。 | Cinemachine 组件与运行时目标的引用在场景载入后验证。 | 边界、冲击、死亡／重开、反向视差。 |
| CT-WORLD-02 | 草地触发动画／环境声／脚步覆盖；离开恢复。 | 触发器退出、场景卸载和声音停止必须幂等。 | 进出草地、连续进出、切场景。 |

## 关键异常

- 无敌期不得重复扣血；同一伤害源重入不得造成多次结算。
- 死亡、重开或切场景必须清理玩家持有物、临时相机状态、慢动作和声音。
- 不在 `Update` 中产生可避免 GC；持续输入和相机计算不分配临时集合。
