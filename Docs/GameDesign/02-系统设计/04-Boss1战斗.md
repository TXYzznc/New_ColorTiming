# Boss1 战斗

| 功能 ID | 行为合同 | 重构与验收重点 |
|---|---|---|
| CT-BOSS1-01 | 开局 11 段弱点：红 4、绿 3、紫 4；显示当前与后续 7 段。 | 弱点序列、HUD 和伤害结算共享同一状态源。 |
| CT-BOSS1-02 | 只有当前同色攻击消耗一段；一次有效命中只消耗一次并同步 Hit、音效、镜头冲击和下一弱点。 | 拒绝错色、无武器和无敌期伤害；覆盖两条可达 Hit 动画（FIX-003）。 |
| CT-BOSS1-03 | 依据三段距离区选择攻击；覆盖攻击 1～6 及同招连续限制。 | 触发器状态离开后复位；状态机不可永久卡住。 |
| CT-BOSS1-04 | Spine `attack` 事件生成攻击实体；攻击3同时覆盖 `atk3_1` 与 `atk3_2`。 | 事件订阅随实体和场景生命周期清理。 |
| CT-BOSS1-05 | 攻击5临时无敌、弱点变暗、准备提示；结束恢复。 | 必须切换专用 Spine 视图和带事件资源（FIX-002），而非字符串比较失效。 |
| CT-BOSS1-06 | 最后一段仅结算一次，停止攻击并经 Loading 自动进入 Boss2。 | 胜利关闭 HUD／临时对象／声音，不出现双重跳转。 |

## 失败模式

- 攻击5结束、中断、场景卸载时必须解除无敌与暗化。
- Boss 实体、攻击子物、Spine 订阅和声音不允许跨场景残留。
- 当前弱点改变后，旧武器提示必须被隐藏，不能指向已过期目标。
