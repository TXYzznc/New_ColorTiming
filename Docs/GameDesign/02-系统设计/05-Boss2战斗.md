# Boss2 战斗

| 功能 ID | 行为合同 | 重构与验收重点 |
|---|---|---|
| CT-BOSS2-01 | 开局 15 段：红 4、绿 4、紫 4、橙 3；当前与未来 7 段顺序正确。 | 橙槽位必须与读取／显示／移除为同一索引（FIX-001）。 |
| CT-BOSS2-02 | 头和尾共享进度，但每个命中只结算一次；12→11 时尾部只激活一次。 | 使用幂等的共享战斗状态，禁止双控制器重复扣段。 |
| CT-BOSS2-03 | 头部根据距离、朝向选择近战、远程或潜地；Spine `atk0/1/2` 生成对应攻击。 | 非法方向、动画无法回 Idle 和中断状态均是回归。 |
| CT-BOSS2-04 | 潜地：入地、关闭本体、轨迹、合法重定位、出土、恢复碰撞。 | 死亡／切场景／中断时清理轨迹和不可见碰撞。 |
| CT-BOSS2-05 | 尾部激活后可潜地、近战、远程；头尾事件、攻击、声音和无敌不串用。 | 每个实体拥有独立事件和音频生命周期，共享的仅是战斗进度。 |
| CT-BOSS2-06 | 最后一段仅触发一次最终结果；头尾、投射物、落点、轨迹和声音均停止，结果可回菜单。 | 结果 UI 阻断底层输入；场景转出后无遗留。 |
