# 音频、世界交互与资源表现

| 功能 ID | 行为合同 | 重构方式／验收 |
|---|---|---|
| CT-AUDIO-01 | BGM、UI、玩家、Boss、环境五类声音可听到；BGM/SFX 设置准确影响对应组。 | 所有播放经 GF.Sound Group；UIForm／实体关闭时按拥有者停止。 |
| CT-AUDIO-02 | 玩家移动随机脚步、Dash、拾取、丢弃、攻击、受击、死亡；草地覆盖脚步集合。 | 草地覆盖可嵌套或幂等恢复；音效实例结束后不可再操作。 |
| CT-AUDIO-03 | Boss1／Boss2 攻击、潜地、受击、胜负音效在事件帧播放，不重复订阅／跨场景残留。 | Spine／动画事件绑定须配套注销；场景卸载停止循环与一次性声音。 |
| CT-WORLD-03 | 草地动画、沙沙声、脚步覆盖与视差相机表现可观察。 | 触发和视觉逻辑与玩家生命周期分离。 |
| CT-ASSET-01 | 三场景无粉材质、Fallback Shader、Missing Script 或 Missing Reference。 | 资源 GUID、URP／Spine 材质、动画、视频、字体、粒子与 Prefab 都必须在目标工程可解析。 |
| CT-ASSET-02 | Boss Spine 透明/PMA、顶点色、遮罩、排序层、弱点填充和材质画面与源工程同状态。 | 通过静态截图和动态录像逐状态比对，不以“无报错”代替视觉验收。 |
