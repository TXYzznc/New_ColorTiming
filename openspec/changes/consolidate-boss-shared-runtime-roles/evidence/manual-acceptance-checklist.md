# Boss1 / Boss2 共享战斗角色人工验收清单

以下项目只检查运行效果，不要求重新制作或调整美术资源。

## BattleHud

- [ ] 从 MainMenu 进入 Boss1，Boss 血条位置、尺寸、背景和 7 个弱点 Item 排列与原 Boss1 正常效果一致。
- [ ] 从 Boss1 进入 Boss2，Boss 血条与 Boss1 使用完全相同的位置、尺寸、背景和排列，不出现第二套血条或空白容器。
- [ ] Boss 受到正确颜色伤害后，弱点 Item 数量按顺序减少；颜色和提示图不串位。
- [ ] 重开关卡、Boss1 切 Boss2、返回菜单再进入后，血条不会残留上一次战斗的 Item 或提示计数。

## 武器生成与丢弃

- [ ] Boss1 仍按 Boss1 规则生成武器，前三次教程显示 Boss1 对应提示美术。
- [ ] Boss2 仍按 Boss2 规则生成武器，前三次教程显示 Boss2 对应提示美术。
- [ ] 玩家主动丢弃和受击丢弃均在当前场景生成正确武器，不重复生成、不丢失、不跨场景引用。
- [ ] 重开／离开场景后，运行时武器被正常回收，后续进入不会复用错误的关卡规则。

## 场景装配

- [ ] Boss1、Boss2 启动时均无 Missing Script、Missing Reference 或“Boss 数量/类型不匹配”异常。
- [ ] Boss1 胜利进入 Boss2、Boss2 结束显示结果的原业务流程保持不变。
- [ ] Boss1/Boss2 各自攻击、动画事件、声音和尾部逻辑保持原效果；本批没有合并这些玩法差异。
