# 变更：补全 Game Scripts 导航与中文注释

## 背景

`Assets/Game/Scripts` 同时包含 GF 通用扩展与 ColorTiming 业务实现，但目录缺少就地说明，且大量脚本没有中文职责头和关键方法注释，阅读者需要反复打开文件推断边界。

## 目标

- 根目录及每一级子目录均提供简短的 `README.md`。
- 每个 C# 脚本开头提供中文职责说明。
- 公开/受保护入口、接口方法、Unity/GF 生命周期及重要私有业务方法提供中文注释。
- 只改变注释与说明文档，不改变任何可执行代码、序列化字段、资源 GUID 或业务行为。

## 非目标

- 不重命名、不移动脚本或目录。
- 不调整架构、API、逻辑、资源和 Prefab。
- 不为显而易见的属性访问器及微小辅助语句堆砌注释。
