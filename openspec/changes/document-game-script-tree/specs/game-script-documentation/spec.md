## ADDED Requirements

### Requirement: 脚本目录必须具备就地说明

`Assets/Game/Scripts` 根目录及其每一级子目录 SHALL 包含简短的 `README.md`，说明该目录中的脚本职责与模块边界。

#### Scenario: 新成员从目录开始阅读

- **WHEN** 阅读者进入任意脚本目录
- **THEN** 无需打开实现文件即可从 README 了解目录用途、直接内容和子模块

### Requirement: 脚本必须具备中文阅读入口

每个 `.cs` 文件 SHALL 在文件开头包含中文职责说明，并在关键方法处包含中文说明。

#### Scenario: 快速浏览业务脚本

- **WHEN** 阅读者打开任意脚本
- **THEN** 可以先从职责头确认所属模块和用途，并从关键方法注释定位主要流程

### Requirement: 文档化不得改变运行行为

本变更 SHALL 只添加或更新注释与说明文档，不得改变可执行 C# 标记、序列化数据、资源引用或运行行为。

#### Scenario: 对比文档化前后代码

- **WHEN** 分别去除基线与当前脚本中的 C# 注释
- **THEN** 两者的有效代码必须完全一致
