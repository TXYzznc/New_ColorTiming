# ColorTiming 重构决策检查点 02

- 日期：2026-08-24

## 已确认决策

1. 渲染基线采用 AI-Friendly-Project 的 URP，不为旧 Built-in 管线保留长期分支。
2. Spine 3.8 作为迁移风险门槛：补齐兼容的 URP Shader 模块，迁移 11 个现有 Boss 材质，并逐场景验证遮罩、填充、混合、颜色与层级表现。
3. 验收采用完整门槛：
   - 源项目与目标项目的功能、资源及序列化引用清单对账。
   - Unity 编译零错误。
   - 核心领域逻辑具备 EditMode 测试。
   - 启动链、场景切换与关键交互具备 PlayMode 冒烟测试。
   - `StartMenu`、`Boss1`、`Boss2` 三场景执行完整人工回归。
   - 画面、音频、视频、输入、动画事件和胜负流程均保留可审计证据。

## 完成定义

迁移只有在全部门槛均有直接证据支持时才算完成。编译成功、单一场景可运行或未发现明显错误，都不能单独证明“无功能遗漏”。
