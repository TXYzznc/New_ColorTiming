# ColorTiming 源项目功能验收清单

> 来源工程：`D:\unity\UnityProject\ColorTimeing\ColorTimeing`  
> 盘点范围：3 个场景、64 个自有脚本、48 个 Prefab、27 个 Animator Controller、148 个 Animation Clip、129 条 Animation Event、19 条 UnityEvent 绑定。  
> 用法：从当前工程的 `Launch` 开始逐项验收。每项记录 **通过 / 失败 / 未测**，失败须附场景、操作、期望、实际、截图或录像时间戳。  
> 判定原则：此文描述的是源工程的可观察功能合同；`FIX-*` 标记的是 OpenSpec 已明确批准的源缺陷修复，验收时应以“修复后的不变量”为准，而不是复现缺陷。

## 0. 验收前提与全局基线

- [ ] 在 Windows、1920×1080 Game View 下测试；从 `Launch` 进入，不能直接运行 Boss 场景。
- [ ] 基础操作可用：移动（Horizontal/Vertical，即 WASD/方向键）、Dash（Jump/Space）、攻击（Fire1/鼠标左键或 Left Ctrl）、丢弃（Fire2/鼠标右键或 Left Alt）、暂停（Escape）、鼠标瞄准、任意键关闭教程。
- [ ] 三个场景切换期间不出现无响应、重复加载、残留 UI/音频/实体，且游戏时间能从暂停与慢动作恢复。
- [ ] 记录所有与源工程不同的可见行为；除下列 `FIX-*` 外，均视为迁移回归而非“可接受优化”。

## 1. StartMenu、设置与加载

### 1.1 菜单视频、背景与按钮反馈

- [ ] 进入 StartMenu 后，`1开头.mp4` 播放一次；结束事件触发后切换为 `2循环.mp4`，后者持续循环且不再跳回开头。
- [ ] 菜单 BGM 播放；按钮悬停和点击都有对应 UI 音效。
- [ ] 主页面可打开“开始/关卡选择”面板、设置面板，并能通过各返回按钮回到正确父页面；页面不重叠、不残留遮罩。
- [ ] “开始”调用 `StartGameBtnDown`，经 Loading 进入 Boss1。
- [ ] 关卡选择中的 `GoTest1` 进入 Boss1，`GoTest2` 进入 Boss2；两个路径都经 Loading。
- [ ] “退出”调用 `ExitGameBtn`；仅在 Player 中验证应用退出，Editor 中不因无法退出而判失败。

### 1.2 设置持久化

- [ ] BGM 开/关按钮状态互斥；关闭后立即静音，重新打开恢复；离开再返回设置页时状态保持。
- [ ] SFX 开/关按钮状态互斥；关闭后按钮 hover/click 和玩法音效不播放，重新打开恢复；状态保持。
- [ ] 操作提示（key tip）开/关按钮状态互斥；状态在菜单、暂停界面及战斗提示中保持一致。
- [ ] 返回 StartMenu 后，视频、BGM、EventSystem 和菜单 UI 各只有一套，不重复播放或叠加。

### 1.3 Loading 与全局暂停

- [ ] 每次场景跳转都有淡入/淡出和进度条；进度单调推进，无黑屏卡死、无重复切换。
- [ ] Escape 打开暂停菜单并将游戏时间暂停；暂停界面仍可点击。
- [ ] 暂停菜单可继续、重开当前关、前往 Boss1/Boss2（`GoNextLevel`）与返回 StartMenu（`BackMenu`）。
- [ ] 暂停菜单也可设置/恢复 key tip；离开暂停后游戏时间为正常值。

## 2. 玩家通用行为

### 2.1 移动、朝向与动画

- [ ] 玩家能上下左右移动，移动速度、朝向翻转、移动/待机动画与输入一致。
- [ ] 鼠标位置转换为世界坐标后决定攻击朝向；左右攻击的生成点和视觉翻转一致。
- [ ] 普通无武器攻击可执行，命中生成 `HitFX_Nor`，并有攻击音效。
- [ ] 角色移动动画包含随机脚步声；草地覆盖行为见第 8 节。

### 2.2 Dash、受击、无敌与死亡

- [ ] Dash 有位移和动画事件定义的无敌开始/结束窗口（`DashWD`、`DashEnd`），窗口外才能受伤。
- [ ] Dash 成功穿过可伤害判定时恢复 1 点生命，并出现约 `0.45` 倍速的慢动作脉冲；暂停、死亡、慢动作之间不会互相卡住。
- [ ] 玩家初始/上限为 5 HP；每次有效受击只扣一格，HUD 同步更新。
- [ ] 受击有击退、受击闪烁/受击动画、短暂无敌；正在持有的武器被强制丢弃。
- [ ] 受击动画事件 `Hit` 仅在有效窗口生效；同一碰撞或连续伤害不会在无敌期重复扣血。
- [ ] HP 归零后停止玩家输入/攻击，播放死亡动画、死亡相机/演出与失败 UI；`DeathOver` 后允许同场景重开。

## 3. 武器、拾取、教程与技能

### 3.1 武器模型与生成规则

- [ ] 七个武器身份均可被拾取、展示、攻击并正确映射图标/动画：普通（nor）、剪刀（jiandao）、锤（chuizhi）、炸弹（zhadan）、刀（meigongdao）、斧头（futou）、飞机（zhifeiji）。
- [ ] 颜色身份正确：红、绿、紫；Boss2 额外有橙。颜色同时影响武器外观、HUD、攻击资源与 Boss 弱点匹配。
- [ ] 靠近地面武器时显示拾取提示；拾取后地面对象消失、手持外观/图标切换。
- [ ] 持武器状态下的主动丢弃有效；受击强制丢弃有效；掉落物有轮廓/提示、淡出或回收，不残留无效对象。
- [ ] Boss1 武器生成器：约每 5 秒检查一次、上限 5 把；随机锚点不与现有武器过近；红/绿/紫与剪刀/锤/炸弹组合均可产生。
- [ ] Boss2 武器生成器：约每 5 秒检查一次、上限 10 把；红/绿/紫/橙与刀/斧头/飞机组合均可产生。
- [ ] 当场上武器尚不足三种颜色或已含当前弱点色时允许随机；否则必须保证补出当前 Boss 弱点颜色。
- [ ] 每次 Boss 有效掉血后隐藏旧提示；战斗前 3 次弱点若场上存在相同颜色武器，显示对应拾取/攻击教程；任意键关闭教程一次且该按键不泄漏为攻击。
- [ ] `FIX-004`：生成计时跨过阈值的同一帧应可生成，不应额外晚一帧；不改变间隔、上限或颜色保底规则。

### 3.2 各武器攻击与 Animation Event

- [ ] 每类攻击由 `Attack` 动画事件在正确帧生成技能/投射物；`PlayAuido`/`PlayAuido_Random` 在正确帧播放音效。
- [ ] 剪刀：红/绿/紫普通攻击均有效；第二段参数 `"2"` 生成第二套剪刀特效；命中后特效能由 `OnFXEnd` 回收。
- [ ] 锤：红/绿/紫攻击与蓄力开始/蓄力完成动画均正确；技能和子碰撞物能结束/回收。
- [ ] 炸弹：红/绿/紫攻击按鼠标世界坐标确定目标；落点、爆炸/命中特效与 `OnFXEnd` 回收正确。
- [ ] 刀：红/绿/紫/橙攻击按鼠标方向；`SkillMove` 在事件窗口驱动位移，`Wudi` 驱动无敌，攻击后附着/脱离关系正确。
- [ ] 斧头：红/绿/紫/橙攻击及蓄力两个阶段正确；子技能/随机命中特效能产生并回收。
- [ ] 飞机：红/绿/紫/橙攻击按鼠标世界坐标飞行/命中；飞行/技能动画的无敌事件和 `OnFXEnd` 回收正确。
- [ ] 所有技能都携带攻击者、武器颜色、武器类型、命中点与参数；命中只对实现 `I_Damage` 的有效目标结算，动画结束事件 `EventEnd_Destroy` 不留残留实体。

## 4. Boss1（11 段战斗）

### 4.1 弱点与受伤

- [ ] 开局随机 11 段弱点：红 4、绿 3、紫 4；HUD 显示当前弱点和后续 7 项，并有当前项提示动画。
- [ ] 只有当前弱点同色的攻击能消耗一段；错色、无武器或无敌期间不掉段。
- [ ] 每次有效命中只消耗一段，同步正确颜色的生命槽、Hit 视觉、命中特效、屏幕冲击和音效；下一弱点亮起。
- [ ] `FIX-003`：Boss1 两条已配置的受击动画都应可达；一次有效命中只播放其中一条。

### 4.2 距离分区、六种攻击与 Spine 事件

- [ ] 玩家进入/离开三种距离区域时，Boss 的攻击选择变化；区域触发器状态不会卡住。
- [ ] 覆盖攻击 1 至攻击 6，且同一攻击的连续选择限制符合源逻辑。
- [ ] 攻击 1、2、3、4、6 的 Spine `attack` 事件分别产生对应实体/判定；攻击 3 的 `atk3_1` 与 `atk3_2` 都要覆盖。
- [ ] 攻击 5：进入后临时无敌，全部弱点变暗；攻击结束/`atk_end` 后恢复可伤害与亮度，`atk_read` 的准备提示正确。
- [ ] `FIX-002`：攻击 5 应切换专用 Spine 视图及带事件的攻击资源，结束后恢复主视图；不应因源工程字符串比较缺陷而恒不切换。
- [ ] 每种攻击都有对应 Boss 音效；攻击结束后动画、碰撞、临时实体和订阅均清理。

### 4.3 胜利流

- [ ] 最后一段同色伤害只结算一次；Boss 停止攻击、胜利表现完成。
- [ ] Boss1 胜利后经淡出/Loading 自动进入 Boss2，不出现重复跳转。

## 5. Boss2（15 段、头尾协同战斗）

### 5.1 弱点、头尾阶段与最终结果

- [ ] 开局随机 15 段弱点：红 4、绿 4、紫 4、橙 3；HUD 当前项与后续 7 项顺序正确。
- [ ] 红、绿、紫、橙分别验证错色拒绝和正确色仅掉一段；橙色武器图标、动画、特效和 HP 槽不串用紫色资源。
- [ ] `FIX-001`：橙色有效命中读取、显示和移除同一橙色槽位；紫色槽位不被错误读取或删除。
- [ ] 头部与尾部共享战斗进度但互不重复结算；头部剩余段数从 12 到 11 时尾部仅激活一次。
- [ ] 最后一段只触发一次最终结果；头、尾、投射物、轨迹、落点标记、音效全部停止/回收；结果 UI 可返回 StartMenu。

### 5.2 头部：距离/朝向选择与潜地

- [ ] 头部根据距离和朝向选择近战、投射/远程与潜地，不出现错误反向攻击或无法回 Idle。
- [ ] 近战/远程 Spine `attack` 事件覆盖 `atk0`、`atk1`、`atk2`；分别产生正确攻击实体、伤害判定和音效。
- [ ] 潜地流程完整：入地 → 禁用本体碰撞/可视状态 → 生成地下轨迹 → 选择合法重定位点 → 出土 → 恢复碰撞与正常状态。
- [ ] 潜地被中断、场景切换或 Boss 死亡时，轨迹和临时对象被清理；不留下不可见碰撞或永久无碰撞。

### 5.3 尾部与投射物

- [ ] 尾部首次激活后的潜地、近战、远程都可执行；尾部 Spine 事件 `atk1` 生成对应攻击。
- [ ] 头尾同时存在时，事件、攻击实体、声音、无敌状态和受击目标不串用。
- [ ] Boss2 攻击 2 及其子对象覆盖目标方向/速度、范围或落点标记、命中与销毁；落点对象能随目标/生命周期正确结束。
